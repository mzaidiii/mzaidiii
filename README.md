### 🏥 SymbioMed — *National Hackathon Finalist*
> **Bridging India's healthcare data with the world** — a full-stack platform that maps India's Namaste medical codes to WHO's ICD-11 standard, enabling hospitals, clinics, and government health platforms to share patient data seamlessly across state and international borders.

**The real problem it solves:**
India's hospitals use different disease classification systems — records can't be shared across states or globally. SymbioMed builds a real-time translation engine between India's Namaste Codes and WHO's ICD-11, directly connecting with the Ayushman Bharat Digital Mission (ABDM).

| Layer | Stack |
|:---:|:---:|
| Frontend | Flutter 3.x + Dart + Provider |
| Backend | Spring Boot 3.x + Java 17 + Hibernate/JPA |
| Database | MySQL 8.0 |
| Auth | JWT + Role-Based Access Control |
| Integration | WHO ICD-11 API · Namaste Code Portal |
| Deployment | Docker-ready · Swagger/OpenAPI docs |

**Validated by Ministry of AYUSH, India &nbsp;·&nbsp; SIH 2025 National Finalist &nbsp;·&nbsp; Tested with 50+ healthcare professionals**
