## Featured Projects

### 🏥 SymbioMed — *SIH 2025 Winner*
Maps India's Namaste medical codes to WHO's ICD-11 so hospitals and government health platforms can share patient data across state and international borders. Validated by the Ministry of AYUSH and tested with 50+ healthcare professionals.

`Flutter` `Spring Boot` `MySQL` `JWT` — [**View Repository →**](https://github.com/mzaidiii/SymbioMed)

### 🐾 Pawffy — *Production App, US Freelance Client*
Two-sided pet-services booking platform — 5 service flows (grooming, vet, boarding, training, daycare) plus adoption, built screen-by-screen from Figma. Flutter frontend on Riverpod 2.0; now building out the companion Spring Boot backend (PostgreSQL, Flyway, JWT) to go with it.

`Flutter` `Riverpod` `Firebase` `Spring Boot` `PostgreSQL` — `Private · Client Work · Active`

### 🎓 GradeLink — *College Social Platform*
Real-time community platform connecting students, alumni, and faculty — post feeds, event boards, alumni networking, synced live via Cloud Firestore.

`Flutter` `Firestore` `Firebase Auth` — [**View Repository →**](https://github.com/mzaidiii/GradeLink)

### 🛒 My Mall Partner — *Vendor Commerce App*
Multi-vendor e-commerce management app taking offline businesses online — real-time admin dashboard, inventory control, and a multi-tenant architecture keeping every vendor's data isolated.

`Flutter` `Firebase` `Firestore` — [**View Repository →**](https://github.com/mzaidiii/My-Mall)
